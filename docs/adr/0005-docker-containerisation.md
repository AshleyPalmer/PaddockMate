# Full-Stack Containerisation for Development and Production

To simplify onboarding and provide a consistent development environment across operating systems (Linux, macOS, Windows/WSL2), we decided to containerise the entire stack using Docker Compose with multi-stage Dockerfiles organised under a dedicated root `docker/` directory (`docker/backend/`, `docker/frontend/`, and `docker/gateway/`). The architecture introduces a dedicated Nginx gateway terminating local SSL for `https://dev.paddockmate.app` and proxying both the frontend UI and `/api/*` backend routes under a single origin, satisfying browser PWA HTTPS requirements while eliminating CORS overhead. The configuration supports live development with volume mounts and hot reloading (Vite HMR and Spring Boot dev reloading) using isolated container volumes for dependency caching (`node_modules` and Gradle cache), alongside production-ready image targets.
